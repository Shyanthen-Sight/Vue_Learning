# 非单文件组件 —— 几个注意点

> 对应文件：`1.基本使用.html`

## 一、回顾基本写法

```html
<!-- 3. 在容器里使用组件标签 -->
<div id="app">
  <school></school>
  <hr>
  <student></student>
</div>

<script>
  // 1. 定义组件（利用 Vue.extend）
  const school = Vue.extend({
    template: `
      <div>
        <h2>学校信息</h2>
        <p>学校名称：{{name}}</p>
      </div>`,
    data() {
      return { name: '清华大学' }
    }
  })

  const student = Vue.extend({
    template: `
      <div>
        <h2>学生信息</h2>
      </div>`,
    data() {
      return { name: '张三' }
    }
  })

  // 2. 注册组件，再创建 Vue 实例
  new Vue({
    el: '#app',
    components: {
      xuexiao: school,
      xuesheng: student
    }
  })
</script>
```

> **顺序不能乱**：先定义组件，再 `new Vue()` 使用（`const` 有暂时性死区，先使用会报 `ReferenceError`）。

---

## 二、注意点

### 1. 关于组件名

**一个单词组成：**

| 写法 | 示例 | 使用标签 |
|---|---|---|
| 全小写 | `school` | `<school></school>` |
| 首字母大写 | `School` | `<School></School>` |

**多个单词组成：**

| 写法 | 示例 | 使用标签 |
|---|---|---|
| kebab-case（短横线） | `my-school` | `<my-school></my-school>` |
| PascalCase（驼峰） | `MySchool` | `<MySchool></MySchool>` |

> ⚠️ 在**非脚手架**环境直接写 HTML 时，PascalCase 写法在部分浏览器中可能不生效，最稳妥的是 **kebab-case**。

**两个坑：**

1. **回避 HTML 已有标签名**：组件名不能叫 `div`、`h1`、`span` 等，否则 Vue 会报错：
   ```
   Do not use built-in or reserved HTML elements as component id: h1
   ```
2. **`name` 配置项**：可以给组件指定 `name`，用于在 Vue 开发者工具中显示更清晰的名字，与标签名无关。

```js
const school = Vue.extend({
  name: 'School',   // 开发者工具里显示的名字
  template: `...`,
  data() { return {...} }
})
```

### 2. 关于组件标签的写法

组件定义好之后，有两种使用方式：

```html
<!-- 写法一：双标签（推荐） -->
<school></school>

<!-- 写法二：自闭合标签 -->
<school />
```

> ⚠️ **推荐使用双标签**。在不使用脚手架（直接写 HTML）时，如果写自闭合标签 `<school />`，浏览器解析 HTML 时会把它当成普通双标签，**后面跟着的兄弟标签会被吞进去**，导致后续内容渲染异常。脚手架（Vue CLI）环境则两者皆可。

### 3. template 必须有且只有一个根元素

组件的 `template` 里只能有一个根标签，否则编译报错：

```js
// ❌ 错误：有两个根元素
template: `
  <h2>学校信息</h2>
  <p>学校名称：{{name}}</p>
`

// ✅ 正确：用一个 div 包起来
template: `
  <div>
    <h2>学校信息</h2>
    <p>学校名称：{{name}}</p>
  </div>
`
```

### 4. 组件的 data 必须写成函数

**组件的 `data` 必须是一个函数，且必须返回一个对象**，不能写成普通对象：

```js
// ❌ 错误：data 写成对象（多个组件实例会共享同一份数据，互相污染）
data: {
  name: '清华大学'
}

// ✅ 正确：data 写成函数，返回一个对象（每个实例有自己独立的数据）
data() {
  return {
    name: '清华大学'
  }
}
```

> 记住口诀：**组件是复用的，data 是私有的。**

### 5. `Vue.extend` 可以简写

定义组件时，`Vue.extend()` 可以省略，直接写配置对象，Vue 内部会自动调用 `Vue.extend`：

```js
// 写法一：完整写法
const school = Vue.extend({ ... })

// 写法二：简写（推荐）
const school = {
  template: `...`,
  data() { return {...} }
}
```

注册时两种写法等价：

```js
components: {
  school   // 等价于 school: school
}
```

### 6. 组件必须注册后才能使用

组件定义好后，使用前必须**注册**：

```js
new Vue({
  el: '#app',
  components: {
    xuexiao: school,   // 局部注册
    xuesheng: student
  }
})
```

- 局部注册：在 `components` 配置项里注册，**只有注册它的 Vue 实例（或其子组件）才能使用**。
- 全局注册：用 `Vue.component('标签名', 组件)` 注册，任何地方都能用。

---

## 三、核心理解（组件本质）

- 组件的本质是一个名为 **`VueComponent`** 的构造函数，由 `Vue.extend()` 生成。
- 每次调用 `Vue.extend()` 都会返回一个**全新的 `VueComponent`**，互不相同。
- 使用组件时，Vue 会帮你 `new` 一个组件实例。
- 组件里 `data`、`methods` 中的 `this`，指向的是**当前组件实例**，不是 Vue 根实例。
