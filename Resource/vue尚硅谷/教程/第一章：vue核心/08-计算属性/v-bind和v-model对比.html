v-bind vs v-model 区别演示

在两个输入框里打字，对比下方「数据」是否跟着变 👇

v-model（双向绑定）

数据 name = {{ name }}  ✓ 跟着变

你打字 → name 数据实时更新

:value / v-bind（单向绑定）

数据 city = {{ city }}  ✗ 不变

你打字 → city 数据毫无变化（只是输入框自己显示了字）

v-bind 的正确用法：给属性动态赋值（数据驱动，单向）

① 点我跳转 —— 链接由数据控制：{{ url }}

isDisabled = {{ isDisabled }}，点右边按钮改变数据，左边按钮跟着启用/禁用

③ 点我 —— 背景色由数据 isActive 控制（当前：{{ isActive }}）

这就是 v-bind 的用途：数据变 → 属性/样式变，方向只有一条
