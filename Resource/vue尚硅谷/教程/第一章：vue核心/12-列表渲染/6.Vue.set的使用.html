Vue.set 的使用

动手试试：先点几个带 ✘ 的按钮，再点带 ✔ 的按钮， 对比页面有没有变化。你会发现：改对象和数组，不是直接赋值就能生效的。

一、为什么直接赋值不生效？

Vue2 的响应式原理是用 Object.defineProperty 给 data 中的每个属性添加 getter/setter。 但 Object.defineProperty 只能拦截"已经存在的属性"：

  • 给对象新增一个 data 里没有的属性（如 sex）→ 没有对应的 setter，改了页面不更新
  • 通过下标直接修改数组元素（如 persons[0] = {...}）→ Vue2 也没有监听下标，改了页面不更新

二、Vue.set 是什么

专门用来解决上面两个问题。三种写法完全等价：

  • Vue.set(target, key, value) —— 全局 API
  • vm.$set(target, key, value) —— 实例方法
  • this.$set(target, key, value) —— 组件内部直接用

三、Vue.set 的用法

  • 对象新增属性：this.$set(this.student, 'sex', '男')
  • 修改数组元素：this.$set(this.student.hobbies, 0, '打篮球')
  • 给数组任意位置放数据：this.$set(this.student.friends, 1, {name:'xxx', age:20})
  • 注意：target 不能是 Vue 实例或 Vue 实例的根数据对象（this.$set(this, 'x', 1) 会报错）

四、数组的常用方法其实都能触发更新

Vue2 重写（劫持）了数组的这些方法，用了它们页面会自动更新，不需要 Vue.set：

  • push、pop、shift、unshift、splice、sort、reverse
  • 所以"新增元素"优先用 push 就行；只有"按下标改/塞"才必须用 Vue.set 或 splice
