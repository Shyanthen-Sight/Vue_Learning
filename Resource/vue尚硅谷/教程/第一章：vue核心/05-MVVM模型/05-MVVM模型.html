MVVM 模型

V —— View（视图）

这是页面模板，用户看到的输入框和文字。

我是一段显示数据的话：{{ msg }}

↓ 数据绑定 / 事件监听（双向） ↓

VM —— ViewModel（视图模型 = Vue 实例）

你在这边输入，Model 里的数据会跟着变，上面的 View 也会刷新。

按 F12 打开控制台，在 console 里输入 vm.msg = '修改了'，再看页面，也会同步更新。

↓ 数据代理 ↓

M —— Model（模型 = data 数据层）

这是数据层，当前 name / msg 的值：

name：{{ name }}，msg：{{ msg }}

现在去上面输入框打字，或按 F12 在控制台执行 vm.msg = 'xxx'，观察 V 和 M 是否同步变化。
